# AI Cloud Recruitment Automation System

I built this project to explore how a fully serverless, event-driven system can automate recruitment workflows that are usually manual and time-consuming. It ingests CVs directly from Gmail, evaluates candidates using AI, and surfaces the best profiles based on configurable recruiter criteria. The system is implemented using AWS serverless services with S3 and Lambda for orchestration, AWS Bedrock (Claude 3.5) for CV analysis and scoring, and a web dashboard deployed on Vercel to configure settings and review results.

Deployed app Link : https://ai-driven-cloud-recruitment-automation-system-r748tcy5s.vercel.app/
